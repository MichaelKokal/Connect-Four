# Connect-Four
<img width="502" height="438" alt="image" src="https://github.com/user-attachments/assets/2fbdaf07-7102-418d-8f6d-14b62f274686" />

A two-player terminal-based Connect Four game built in C++. Players take turns dropping pieces into a 6x7 board, competing to connect four in a row horizontally, vertically, or diagonally.
Features

Full 6x7 board with real-time display after each turn
Detects wins in all four directions — horizontal, vertical, and both diagonals
Tie detection when the board is completely filled
Input validation to prevent invalid or full-column moves
Exit option mid-game with -1

Built With:
-------------
C++
2D array board logic built from scratch

How To Play:
-------------
Red always goes first
Enter a column number (1-7) to drop your piece
First to connect four in any direction wins
Enter -1 to exit at any time
